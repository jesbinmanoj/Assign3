# Employee App Backend Integration

Assignment 3: Node.js, Express, and MongoDB Atlas backend for the provided Employee App frontend.

## Setup

1. Install Node.js.
2. Run `npm install` in the `Casestudy2` folder.
3. Copy `.env.example` to `.env` and set `MONGO_URI` to your MongoDB Atlas connection string.
4. Run `npm start`.
5. Open `http://localhost:3000`.

Never commit `.env` or real database credentials.
